# 机器学习势函数的采样策略：从第一性原理到目标感知分层框架

:::{note}
本文讨论机器学习原子间势的数据采样与训练数据优化，并以 PyTorch 后端的 SeZM / DPA4 作为案例。SeZM（Smooth Equivariant Zone-bridging Model）是一个面向分子动力学的 SO(3) 等变模型，即模型特征会按照三维空间旋转规律一致变换；DPA4 是它在 DPA 模型系列中的名称。除明确注明外，第五部分提出的框架尚属于待验证的研究方案，而非已经实现或验证的算法。
:::

机器学习原子间势（machine-learning interatomic potential, MLIP）以元素种类、原子坐标和晶胞为输入，近似量子力学势能面，并据此预测体系能量、原子力和应力。其标准开发流程是：用密度泛函理论（density functional theory, DFT）等第一性原理方法生成参考标签，训练 MLIP，在目标体系中运行模拟，再根据模型暴露出的数据缺口补充标注。由模型参与选择下一批待标注构型并迭代更新的过程称为**主动学习（active learning）**。

MLIP 的精度上限由训练数据与模型表达能力共同决定，而"用哪些数据"归根到底是一个**采样**问题：从近乎无限的构型空间、或从已有的上亿条数据中，挑出最值得投入昂贵第一性原理计算的一小部分。本文系统梳理该领域现有的采样与不确定性量化算法，剖析各自有效与失效的机理，并在最优实验设计、信息匹配、神经正切核、数据去重和物理审计等已有工作的基础上，组织出一套待验证的**目标感知分层采样框架**。框架覆盖数据清洗、快速势函数生产、蒸馏数据集构建与跨领域数据整合四类任务；潜在贡献主要在于组件组合、物理约束和 SeZM 实例化，而不是把每个组成算法都重新声明为原创。

全文分为六部分：第一部分建立问题的数学形式，并交代大原子模型时代的数据格局；第二部分分析不确定性与信息量的各类度量；第三部分对现有采样算法作全景分类与逐一剖析；第四部分用统一的决策视角比较不同方法及其适用边界；第五部分给出待验证的分层采样框架；第六部分给出各任务的完整流程、验证方案与落地路径。

# 第一部分　问题的本质

## 1. 采样到底在优化什么

### 1.1 优化目标：部署风险

训练数据规模只是手段，最终目标是模型在实际应用中的可靠性，例如分子动力学、相图计算、过渡态搜索和材料性质预测的误差。

用数学形式表示如下：

- $x$：一个原子构型（原子坐标、元素种类、晶胞）。
- $f_\theta(x)$：参数为 $\theta$ 的模型对 $x$ 的预测（能量、力、应力）。
- $f^\star(x)$：真值，也就是 DFT（密度泛函理论，目前主流的第一性原理方法）给出的答案。
- $\rho_\text{deploy}(x)$：**部署分布**——实际应用中模型会访问的构型概率分布。举例：若要研究 1000 K 下某固态电解质里锂离子如何扩散，那么 $\rho_\text{deploy}$ 就是该体系在 1000 K 分子动力学轨迹上访问到的构型分布。

理想目标是最小化**部署风险（deployment risk）**：

```math
R(\mathcal{S}) \;=\; \mathbb{E}_{x \sim \rho_\text{deploy}} \Big[\, L\big(f_{\theta(\mathcal{S})}(x),\, f^\star(x)\big) \Big],
```

其中 $\mathcal{S}$ 是**挑出来送去做 DFT 并用于训练**的构型子集，$\theta(\mathcal{S})$ 是在 $\mathcal{S}$ 上训练得到的参数，$L$ 是预测误差（通常是能量与力的加权平方误差）。$\mathbb{E}$（期望）在这里就是"按部署分布加权求平均"。于是采样问题的严格表述是：

```math
\mathcal{S}^\star \;=\; \arg\min_{\mathcal{S}\subset \mathcal{P},\; |\mathcal{S}|\le B}\; R(\mathcal{S}),
```

即：在候选池 $\mathcal{P}$ 里、在标注预算 $B$（能做多少次 DFT）之内，挑一个子集，使得**训练之后**的模型在**部署分布**上误差最小。

这个看似简单的表述，立刻暴露了三个几乎所有实用方法都忽略、却决定成败的事实：

1. **目标里有 $\rho_\text{deploy}$。** 一个构型值不值得标注，应相对于部署时的出现概率与影响来衡量，而不是只看它在候选池中是否独特。若某类构型在声明的目标分布中没有权重，它就不会降低该目标下的风险。**目标不是无条件覆盖整个构型空间，而是覆盖声明的应用分布。**

1. **目标里是"训练之后"的模型 $\theta(\mathcal{S})$。** 要寻找的不是当前模型最不确定的点，而是标注后能使未来模型误差下降最多的点。二者并不总是一致，即**不确定不等于值得标注**。

1. **$\mathcal{S}$ 是一个集合，不是一堆孤立的点。** 两个各自看都很有价值、但彼此几乎一模一样的构型，一起选进来就是浪费预算。批量选择必须考虑**冗余**。

这三点——**代表性、误差下降、去冗余**——是贯穿全文的三把尺子。可以发现，现有方法的每一次失败，几乎都能归因于漏掉了其中之一。

### 1.2 数据规模、计算成本与边际收益

增加 DFT 数据通常有助于提高覆盖度，但这一策略受到两类限制。

**其一，标注成本较高。** 一个中等体系的单点 DFT 可能消耗数十个 CPU 核·时，大规模数据标注和大原子模型训练还会占用大量 CPU / GPU 资源。采样的意义是在固定预算下提高每次标注的有效信息量。

**其二，也是更深刻的——盲目堆数据的边际收益递减，甚至可能有害。** 多类深度模型的经验标度律显示，误差常随数据量按幂律缓慢下降；具体指数依赖任务、模型和训练预算，不能用固定的"十倍数据减半误差"概括。若冗余数据里混入 DFT 未收敛、磁态不一致或赝势设置冲突等问题，模型还会受到噪声与系统偏差限制。MatPES 的实验表明，约 40 万条精心采样的数据可以在若干基准上与更大数据集竞争，但这种比较同时受 DFT 设置、候选空间与模型影响，不能简单归因于样本数量。

### 1.3 采样价值的来源：区分四类误差

评估一个构型是否值得标注，需要先区分四类误差来源：

- **认知不确定性（epistemic uncertainty）**：因为训练数据不足、参数尚未被约束而产生，可通过增加相关且可信的标注降低。主动学习主要瞄准这一项。
- **偶然不确定性（aleatoric uncertainty）**：在任务定义完整之后仍存在的随机性或不可解析变量。对固定几何、固定电子态和固定 DFT 设置的确定性标签，这一项通常不是主导来源。
- **可修复的标签缺陷与任务歧义**：自洽场迭代（self-consistent field, SCF）未收敛、k 点或截断能不足属于可通过更严格复算降低的数值误差；不同赝势、泛函、Hubbard $U$ 属于不同任务定义；多个磁态或电子态可能表示遗漏状态变量。这些都不能统一称为不可约偶然噪声，更不能直接删除，而应按 §23 做筛查、复算、补充元数据或拆分任务。
- **模型失配偏差（model bias）**：模型架构若无法表达真实势能面，或基础模型在某个区域产生系统性错误，那么即使后验方差很小，真实误差仍可能很大。

在线性化平方损失下，部署风险可近似分为

```math
R_\text{deploy}
\;\approx\;
\underbrace{\operatorname{tr}(\Sigma M_\text{deploy})}_{\text{估计方差}}
\;+\;
\underbrace{\mathbb{E}_{\rho_\text{deploy}}\!\left[b(x)^2\right]}_{\text{模型偏差}}
\;+\;
\underbrace{\sigma_\text{irr}^2}_{\text{不可约噪声}}.
```

采样通常只能直接压低第一项；标签缺陷需要复算或任务重构，模型偏差需要改变模型、状态变量或损失。后文的 Fisher / Laplace 设计因此是**部署风险中认知方差部分的代理目标**，不是完整风险本身。对于扩散系数、相变温度、自由能等轨迹泛函，逐帧能量/力方差也不等同于最终物性的误差；若应用目标是这些量，目标矩阵还应包含物性对模型参数的响应。

## 2. 大原子模型时代的数据长什么样

MLIP 的研究范式正从针对单一体系定制的模型，转向覆盖多种元素、相结构和键合类型的**大原子模型（Large Atomistic Model, LAM）**。SeZM / DPA4 属于这一类模型，其多源训练数据带来了新的采样与权重分配问题。

### 2.1 数据集已扩张到上亿级，且生成方式多样

近年开源原子数据集的规模从早期数万条迅速膨胀到数千万乃至上亿条。下表汇总了主流数据集及其核心采样方法——注意最后一列，它决定了每个数据集"脏"和"冗余"的方式：

| 数据集  | 研究对象        | 规模（约百万） | 核心采样方法                                            |
| ------- | --------------- | -------------- | ------------------------------------------------------- |
| OC20    | 金属表面吸附    | 134            | 规则位点枚举 + 随机表面搜索 + 轨迹采样 + 随机扰动       |
| OC22    | 氧化物表面吸附  | 8              | 规则位点枚举 + 随机构象生成 + 轨迹采样                  |
| ODAC23  | MOF 空气捕集    | 36             | 蒙特卡洛采样 + 轨迹采样                                 |
| OMat24  | 无机晶体        | 100            | 扰动玻尔兹曼采样 + 轨迹采样 + 随机扰动                  |
| OMol25  | 有机分子/配合物 | 101            | 轨迹采样 + 反应路径采样 + 片段组装                      |
| OC25    | 固液界面/催化   | 7              | 约束空间内的随机采样                                    |
| ODAC25  | 增强版 MOF 捕集 | 70             | 功能化修饰 + 合成框架生成 + GCMC 模拟                   |
| OMC25   | 分子晶体        | 25             | 实验分子基底 + 随机晶格组装 + 刚体压缩预优化 + 轨迹采样 |
| OPoly26 | 聚合物/软物质   | 6              | 规则组装 + 轨迹采样                                     |

其中，MOF 指金属有机框架（metal–organic framework），GCMC 指巨正则系综蒙特卡洛（grand canonical Monte Carlo）。

这张表有两个要点。**其一，绝大多数数据由"轨迹采样 + 随机扰动"产生**——这两种方式容易产生大量相邻冗余构型，并提高异常标签审计的工作量（§2.2、§17）。**其二，不同数据集的 DFT 设置（泛函、赝势、收敛判据、Hubbard $U$）互不相同**，因此它们的能量与力标签在数值上**不构成一个自洽的统一监督目标**。这也是大原子模型通常采用多任务学习的原因之一（§2.4）。

### 2.2 原子数据的"长尾"：高密度冗余区与低密度关键区并存

与语言、图像这类近似独立同分布的数据不同，原子结构数据被三条物理规律绑住：**平移/旋转/置换对称性、局域原子环境的相关性、势能面的连续光滑性**。后果是：构型样本之间高度相关，在高维原子环境空间里形成极不均匀的分布。

最典型的是**分子动力学轨迹**：相邻时间步的构型只差原子位置的微小连续扰动，它们的描述子（把局域原子环境编码成数值向量的表示，详见 §4.1）会在特征空间中高度聚集。于是数据分布呈现"**高密度冗余区（平衡态附近，样本多且信息重复）+ 低密度关键区（构型跃迁、相变、高能区，样本少但可能承担关键约束）**"的长尾结构。QUESTS 的信息论分析（§12）在其研究的数据集上发现，主动学习第三轮之后新增环境中不到 5% 满足其新颖性判据，说明后期采样可能存在较高冗余。

这种长尾结构为数据压缩提供了空间：高密度区通常包含更多重复信息，而低密度区域可能包含关键构型。仅追求均匀覆盖或直接删除离群点，都可能改变目标分布或遗漏重要环境。

### 2.3 跨数据集的冗余：全局不同，局域重叠

大原子模型同时使用多个数据集，冗余问题被进一步放大。关键洞察是：**冗余发生在"局域原子环境"层面，而不是"整个结构"层面。** OMol25 的小分子、OMat24 的无机晶体、OC20/OC22 的表面吸附结构，作为整体结构看毫不相干；但把它们拆成一个个原子的局域环境（一个原子 + 它截断半径内的邻居），就会发现大量重叠——比如"体相金属原子"这种局域环境在无数结构里反复出现。

现有大模型（如 UMA）训练时，只凭经验给各数据集分配权重，并没有对这种跨数据集冗余做系统分析。不加区分地整合，可能一边浪费算力重复学习极其常见的环境，一边淹没了对泛化关键的稀有环境。**这意味着采样不能只在单个数据集内做，还必须做跨数据集的联合去冗余与加权**——这是 LAM 时代特有的新维度，§25 专门处理。

### 2.4 为什么大原子模型用"多任务学习"，以及它给采样带来什么

因为不同数据集的标签不自洽（§2.1），无法拼成一个统一的回归目标。主流做法是**多任务学习**：共享一个统一的原子环境表示（描述子主干），但给每个数据集配一个独立的"读出头"和独立的损失函数——每个数据集是一个"任务"。这样既能跨数据域联合学到通用表示，又不强行让互相矛盾的标签对齐。

这个架构给采样带来两个直接后果：

- **"部署分布"可能是多个。** 通用势要同时服务多个下游领域，于是 §1 的单个 $\rho_\text{deploy}$ 变成一组带权重的分布 $\{\rho_\text{deploy}^{(t)}\}$。采样目标要对它们加权（§25）。
- **数据集权重本身就是一个待优化量。** 哪个数据集该多采、哪个该少采、哪个已经饱和，应当由"它对模型泛化的边际贡献"决定，而非凭经验主观设定。这把"采样"和"数据集加权"统一成了同一个问题（§25）。

## 3. 四类任务其实是同一个问题

势函数生产中的数据工程需求可以归纳成四类任务。它们表面不同，实际是同一个优化问题（§1.1 的部署风险最小化）在**部署分布、候选池、标注成本**三个旋钮上的不同设定。看清这一点，就不必为每个任务发明一套互不相干的启发式。

| 任务             | 部署分布 $\rho_\text{deploy}$ | 候选池 $\mathcal{P}$         | "标注"是什么                           | 突出的额外维度                    |
| ---------------- | ----------------------------- | ---------------------------- | -------------------------------------- | --------------------------------- |
| **① 数据清洗**   | 宽泛通用，或关注的下游合集    | 已有的大数据集本身           | 标签已存在，问题是"留哪些、删哪些"     | 标签质量审计 + 可扩展性（上亿条） |
| **② 快速生产**   | 目标应用体系的分子动力学系综  | 用预训练模型跑的廉价 MD 轨迹 | 少量、昂贵的 DFT                       | 预算极小，必须紧贴部署            |
| **③ 蒸馏数据集** | 学生模型自己跑 MD 的轨迹      | 海量低成本构型               | 教师模型前向，远低于 DFT 成本          | 标注成本较低，瓶颈转为选点与训练  |
| **④ 跨领域整合** | 多个下游领域的加权合集        | 多个异构大数据集             | 标签已存在，问题是"各留多少、各占多重" | 跨域冗余 + 多任务权重分配         |

**关键结论：四类任务共享降低部署风险这一决策目标**，差别在于部署分布、标注成本和跨域权重。同一套数学可以为四者提供统一的组织方式，但不同任务的噪声模型、可训练参数子空间和最终物性目标仍需分别定义。第五部分据此给出一个待验证的分层研究框架。

## 4. 反复出现的数学工具

现有方法看似多样，实则反复依赖以下几样工具。本节作为全文的数学预备，逐一给出其定义与直觉。

### 4.1 描述子：把原子环境变成向量

神经网络势通常不直接使用原始坐标，因为同一个物理构型在整体平移、旋转或交换同种原子的编号后，坐标数值会改变而物理性质不应改变。模型因此先把每个原子 $i$ 的**局域环境**（截断半径内的邻居）映射成满足这些对称性的**描述子向量** $d_i \in \mathbb{R}^c$。整个结构可表示成原子描述子的集合，或通过池化操作——例如求和、平均或加权聚合——得到结构级向量。

几乎所有多样性或相似性方法——例如最远点采样、聚类和信息熵——都在描述子空间中计算距离。描述子有两大流派：一是**解析式描述子**，如 Behler–Parrinello 对称函数、SOAP（原子位置平滑重叠）和双谱分量，它们用固定公式编码；二是**学习型表示**，即预训练神经网络学到的原子嵌入，如 SeZM、MACE 和 DPA 的中间特征。两者都为环境覆盖与相似度提供数值度量。

### 4.2 梯度特征与神经正切核

一个训练好的神经网络，在它收敛到的参数 $\theta^\star$ 附近，可以做**一阶泰勒展开**，即用局部直线或平面近似复杂函数。对标量输出——例如结构总能量 $E$——有：

```math
E_\theta(x) \;\approx\; E_{\theta^\star}(x) \;+\; (\theta-\theta^\star)^\top\, \underbrace{\nabla_\theta E_{\theta^\star}(x)}_{\displaystyle \phi(x)}.
```

这里的 $\phi(x) = \nabla_\theta E(x)$ 叫做**梯度特征（gradient feature）**。它是一个和参数同维度的向量，物理含义是：**输出对每个参数扰动有多敏感、朝哪个方向敏感**。

这个展开的意义在于：**在 $\theta^\star$ 的局部邻域，神经网络可近似为一个以 $\phi(x)$ 为特征的线性模型**。参数偏移 $\theta-\theta^\star$ 是线性模型的权重，$\phi(x)$ 是特征。这就是"**神经正切核（Neural Tangent Kernel, NTK）**"的核心思想。线性回归的贝叶斯后验与最优实验设计由此可以作为深度网络的局部近似，但不能原封不动地推广到大幅参数更新。这个近似在小学习率、有限步数的基础模型微调中通常比从头训练更合理，其质量仍须通过实际微调后的风险下降实验验证。

**与 SeZM 接口适配的特例——最后一层特征。** 完整的 $\phi$ 维度等于参数总量，可能达到千万量级，直接使用成本很高。若只对**最后一层线性输出头**求梯度，设原子能量是仿射映射 $E_i = \mathbf{w}\cdot \mathbf{a}_i + b$，其中 $\mathbf{a}_i$ 是倒数第二层的激活，即最后隐藏特征，那么：

```math
\nabla_{\mathbf{w}} E_i = \mathbf{a}_i,\qquad
\nabla_{\mathbf{w}} E = \sum_i \mathbf{a}_i.
```

也就是说，**相对于最终输出权重 $\mathbf{w}$，结构总能量的最后一层梯度特征恰好是所有原子隐藏特征之和**。SeZM 的 `dp embed` 命令已经把它作为结构特征 `structural_feature` 导出，逐原子的隐藏激活则作为原子特征 `atomic_feature` 导出（详见 §28）。若把输出偏置也纳入贝叶斯线性头，完整特征还应附加原子数或分类型原子计数。

这个结论只覆盖最终输出权重，不覆盖低秩适配（low-rank adaptation, LoRA）或其他实际微调参数。LoRA 冻结原权重，只训练低秩增量矩阵；SeZM 的 LoRA 流程还会更新拟合网络、径向网络、特征级线性调制（feature-wise linear modulation, FiLM）、归一化层和注意力层等参数。这些参数的切向特征需要额外反向传播，不能由 `structural_feature` 代替。LoRA 采用零初始化 $B$ 时，初始时刻相对于 $A$ 的梯度还为零，因此把预训练主干的 Fisher 直接映射到 LoRA 的 $(A,B)$ 坐标也没有严格依据。

### 4.3 Fisher 信息矩阵：模型"已经知道了什么"

贝叶斯推断用三个对象描述参数不确定性：**先验分布**表示观察数据前对参数的认识，**似然函数**描述给定参数时观测数据出现的可能性，二者结合得到观察数据后的**后验分布**。后验协方差描述参数在各方向上的剩余不确定性；协方差越小，表示参数越确定。

在固定特征、标量高斯回归模型

```math
y=\phi(x)^\top\theta+\epsilon,\qquad \epsilon\sim\mathcal{N}(0,\sigma^2)
```

中，可以定义后验精度矩阵

```math
A \;=\; \Lambda_0 \;+\; \frac{1}{\sigma^2}\sum_{x\in\mathcal{S}} \phi(x)\,\phi(x)^\top.
```

直觉：$A$ 记录了"训练集在参数空间的每个方向上，各积累了多少信息"。某个方向上样本多、$\phi$ 分量大，$A$ 在那个方向就"硬"（信息足），模型在那个方向就确定；反之则"软"。$\Lambda_0$ 是先验精度（最简单时取 $\lambda I$），$\sigma^2$ 是标量标签噪声方差。

雅可比矩阵（Jacobian）把多个输出对多个参数的一阶导数排列成矩阵，描述局部敏感性；海森矩阵（Hessian）是标量目标对参数的二阶导数矩阵，描述局部曲率。在一般神经网络中，必须区分四个容易混淆的对象：

- **Fisher 信息矩阵**：对模型预测分布中的标签取期望；
- **广义 Gauss–Newton（generalized Gauss–Newton, GGN）矩阵**：输出雅可比矩阵与损失关于输出的 Hessian 组合而成；
- **经验 Fisher（empirical Fisher）**：由已观测样本梯度外积构造；
- **完整损失 Hessian**：还含残差与网络二阶导产生的项。

它们只在特定模型和损失下等价。后文若使用“Fisher”，默认指固定线性化与高斯似然下的 GGN / 后验精度近似，而不是一般神经网络完整 Hessian 的同义词。

在上述固定特征线性高斯模型中，有两个闭式结论：

**（a）参数的后验协方差就是 $A^{-1}$。** 训练集提供的信息越多，$A$ 越大，$A^{-1}$ 越小，参数越确定。

**（b）任意测试点 $x$ 的预测方差有闭式解：**

```math
\mathrm{Var}\big(E(x)\big) \;=\; \phi(x)^\top A^{-1}\phi(x).
```

这个量叫**杠杆（leverage）**。它是该近似模型对 $x$ 的认知不确定性：只需要一个训练好的模型与选定参数子空间的特征即可计算，不需要训练多个独立模型。多模型预测分歧与它都试图刻画认知不确定性，但二者不是一般条件下的严格等价量。

### 4.4 最优实验设计：D、A、I 三种"最优"

"该选哪些点做实验（标注）"是统计学一个有百年历史的问题，叫**最优实验设计**。它有三种经典问法，对应三种"最优"，MLIP 领域的采样方法几乎都能对号入座：

- **D-最优（D-optimality）**：最大化 $\det(A)$（行列式，几何上代表"体积"）。$\det(A)$ 是训练点的特征向量在参数空间张成的平行多面体的体积。最大化体积 = 挑最独特、最不共线、最"撑得开"的点。**MTP/ACE 的 MaxVol 外推度就是它**（§15.2）。

- **A-最优（A-optimality）**：最小化 $\mathrm{tr}(A^{-1})$（$\mathrm{tr}$ 是矩阵的迹，即对角线之和）。让所有参数方向的平均不确定性最小。

- **I-最优（I-optimality，也叫 V-最优、积分方差最优）**：最小化在**部署分布上加权**的平均预测方差：

```math
R \;\propto\; \mathbb{E}_{x\sim\rho_\text{deploy}}\big[\phi(x)^\top A^{-1}\phi(x)\big] \;=\; \mathrm{tr}\!\big(A^{-1} M_\text{deploy}\big),\qquad
M_\text{deploy} \;=\; \mathbb{E}_{x\sim\rho_\text{deploy}}\big[\phi(x)\phi(x)^\top\big].
```

这里 $M_\text{deploy}$ 是**部署分布上的特征二阶矩**，代表"未来会朝哪些参数方向提问"。该式是 §1.1 完整部署风险中**线性化后验方差项**的可计算形式；只有当模型偏差可忽略、平方损失与噪声模型正确、并且 $M_\text{deploy}$ 使用与最终损失一致的输出和权重时，它才近似完整部署风险。经典 I/V-最优设计已系统研究目标分布；Kurniawan、Neilsen、Francis 等的信息匹配最优实验设计进一步用目标量（QoI）的 Fisher 信息约束训练数据，Kurniawan、Williams、Samanta 等又在 2026 年将其用于面向材料强度的专用原子势主动学习。第五部分讨论这些思想在 SeZM 微调与数据工程中的实例化。

### 4.5 核密度估计与信息熵：不用模型也能量"新颖度"

除了走"参数/梯度"这条线，还有一条完全不碰模型参数、只看**数据分布**的线。给定一堆描述子 $\{X_i\}$，用**高斯核**估计它们在特征空间的概率密度（核密度估计，KDE——直觉是"在每个数据点上放一个小钟形帽子，叠起来就是密度"），再算**信息熵**：

```math
\mathcal{H} \;=\; -\frac{1}{n}\sum_{i=1}^n \log\!\Big[\frac{1}{n}\sum_{j=1}^n K_h(X_i, X_j)\Big],\qquad
K_h(X,Y)=\exp\!\Big(-\frac{\lVert X-Y\rVert^2}{2h^2}\Big).
```

熵越大，表示数据在特征空间铺得越开、越多样。$h$ 是核密度估计的主要带宽超参，决定"多近算近"；描述子、归一化和参考集同样影响结果。还能定义单个点的**微分熵**（QUESTS 称之为"惊讶度 surprise"）：

```math
\delta\mathcal{H}(Y\mid\{X\}) \;=\; -\log\Big[\sum_{i} K_h(Y, X_i)\Big].
```

在 QUESTS 的描述子、带宽和归一化约定下，$\delta\mathcal{H}>0$ 被解释为相对于参考集 $\{X\}$ 的新颖环境，$\delta\mathcal{H}\le 0$ 被解释为已有覆盖。它与 §4.3 的杠杆都试图刻画训练分布之外的新颖性，但一个来自核密度，一个来自线性化后验，二者不是同一统计量。这条路线的代表是 QUESTS（§12）。

### 4.6 协变量漂移与在线候选生成

协变量漂移是分子动力学势函数的重要失效模式之一。

在数据集 $\mathcal{D}$ 上训练模型，模型主要受到该数据分布的约束。用于分子动力学时，每一步预测误差都会影响下一步构型，轨迹可能逐渐进入 $\mathcal{D}$ 未覆盖的区域，并进一步放大误差，最终导致原子位置或能量发散。训练分布与模型实际访问分布的差异称为**协变量漂移（covariate shift）**。

模仿学习里的数据集聚合（Dataset Aggregation, DAgger）在特定专家策略、动作损失与无遗憾学习（no-regret learning）假设下，可把行为克隆的轨迹误差界从 $O(T^2)$ 改进为 $O(T)$。自治连续动力学、混沌误差传播和力场回归并不自动满足这些假设，因此这个结论不能直接作为 MLIP 的理论保证。

不过，DAgger 提供了有价值的设计启发：**候选池应包含当前模型在部署条件下自己访问的构型，而不应只依赖一次性静态生成。** 这种按照当前模型访问分布收集数据的方式称为**在线策略采样（on-policy sampling）**。DPGEN 用当前模型运行 MD 产生候选，正是这一原则的工程实例。静态随机扰动池仍可作为补充探索源，但单独使用会遗漏模型自身诱导的分布漂移。第五、六部分按“受 DAgger 启发的在线策略迭代”表述，不再声称继承其误差界。

## 5. 一张贯穿全文的判据表

综合第一部分，可以从下面六个维度比较采样与不确定性方法。§20 的表格只表达各方法的设计覆盖范围，不代表这些能力已被理论保证或实验验证。

1. **新颖性**：它能否识别"训练集还没覆盖"的构型？（对应 $\phi^\top A^{-1}\phi$）
1. **代表性**：它是否相对于**部署分布**来衡量价值？（对应 $M_\text{deploy}$）
1. **去冗余**：批量选择时，它是否避免选一堆彼此雷同的点？
1. **正确性**：它能否区分认知不确定性（该追）与偶然噪声（该躲）？
1. **抗漂移**：候选池是否按在线策略产生？
1. **可扩展/免调参**：单模型能否胜任、能否扩到上亿条、超参是否稳健？

# 第二部分　不确定性与信息量分析

不确定性量化（uncertainty quantification, UQ）为候选构型提供模型可信度或信息量评分，是许多主动学习方法的基础。本部分比较这些评分度量的对象、计算方式与适用条件。

## 6. 预测不确定性的概率分解

§1.3 已从数据工程角度区分误差来源。对概率预测模型，总预测方差还可写成：

```math
\underbrace{\mathrm{Var}[y\mid x]}_{\text{总不确定性}} \;=\; \underbrace{\mathbb{E}_\theta\big[\mathrm{Var}(y\mid x,\theta)\big]}_{\text{偶然（数据噪声）}} \;+\; \underbrace{\mathrm{Var}_\theta\big[\mathbb{E}(y\mid x,\theta)\big]}_{\text{认知（模型分歧）}}.
```

- **偶然不确定性**：给定完整输入和模型参数后，输出仍存在的条件随机性。对固定任务定义下的确定性 DFT 标签，它通常不是主要来源；SCF 未收敛或设置不一致属于可修复标签缺陷，而非不可约随机性。
- **认知不确定性**：参数和模型结构尚未被数据充分约束而产生的变化。在模型设定合理时，增加相关数据通常可降低这一项。

主动学习通常希望优先降低认知不确定性；标签审计则关注可修复数值错误、任务歧义与异常数据。两者可能产生相似的高残差信号，因此必须通过复算和任务元数据区分。

## 7. 委员会查询与深度集成

### 7.1 方法原理

**深度集成（deep ensemble）/ 委员会查询（query by committee, QbC）** 用同一份数据和不同随机初始化独立训练 $k$ 个模型（通常为 4–8 个），再用成员预测差异表示模型分歧。DPGEN 采用了这一思路。

DPGEN 使用的指标称为**模型分歧指标（model deviation）**，取各原子受力预测的标准差在全体原子上的最大值：

```math
\varepsilon_\text{devi} \;=\; \max_i\; \sqrt{\big\langle\, \lVert \mathbf{F}_i^{(m)} - \langle\mathbf{F}_i\rangle_m\rVert^2 \,\big\rangle_m}.
```

DPGEN 通过上下两个阈值构造信任窗口：低于下限的构型被视为已有模型可处理，高于上限的构型被视为高风险或可能不适合直接标注，中间区域作为候选送入 DFT。阈值需要针对体系和单位校准。

### 7.2 为什么"分歧"能代表认知不确定性

在贝叶斯模型中，基于分歧的贝叶斯主动学习（Bayesian Active Learning by Disagreement, BALD）用预测与参数之间的**互信息**度量一种认知不确定性；委员会方差则把不同成员的预测分歧作为经验代理。若训练数据充分、优化稳定，成员预测通常趋于一致；数据稀缺时，不同初始化可能得到不同函数。深度集成还可探索多个函数空间模态，这解释了其经验效果。普通深度集成成员并不是严格的后验样本，因此“分歧”不等于互信息，只能视为近似信号。

### 7.3 优势与适用边界

**优势**：实现简单，不要求修改模型；用原子力而非总能量构造指标，对局部环境异常更敏感；与在线轨迹生成结合后已有大量应用经验。

**但它成本较高且不能完整回答采样问题，原因有四**：

1. **集成是成本较高、且没有普适校准保证的不确定性近似。** 训练 $k$ 个成员使训练与推理成本近似增加 $k$ 倍。在线性高斯近似中，杠杆 $\phi^\top A^{-1}\phi$ 可由单模型特征解析计算；深度集成则通过训练随机性在函数空间探索多个解。二者都试图刻画认知不确定性，但并不严格等价。多个基准指出，集成不确定性与真实误差的相关性依赖模型、数据和分布偏移，尤其在分布外区域可能系统性高估或低估，因此通常仍需校准。

1. **单点分歧不包含部署权重和批量联合信息。** 模型分歧指标主要回答模型对单个构型的分歧程度，不直接考虑该构型在目标分布中的重要性，也不自动扣除同一批候选之间的重复信息。

1. **高分歧来源并不唯一。** 未收敛标签、异常几何和数据覆盖不足都可能导致分歧，经验阈值无法自动区分这些来源。

1. **系统性偏差可能不可见。** 当所有成员共享相同架构缺陷或标签偏差时，它们可能给出一致但错误的预测。

**小结**：DPGEN 的模型分歧指标是经过大量实践验证的认知不确定性代理，但代价是 $k$ 倍训练，而且单点阈值本身不处理部署代表性与批量冗余。它的信任窗口可以理解为对信息不足、可计算和高风险区域的经验划分。后文框架的目标不是否定 DPGEN，而是检验单模型目标感知设计能否在特定场景下以更低成本达到相同或更好的数据效率。

## 8. 单模型梯度特征与后验近似

线性化后验允许从单个模型的参数梯度直接构造认知不确定性，不再依赖多个独立训练的成员。

### 8.1 做法

无需训练集成模型，直接用 §4.2 的梯度特征 $\phi_i = \nabla_\theta E_\text{at}(S_i)$（用每原子能量以避免偏向大体系）定义单模型不确定性。常见形式有两种：

- **距离型**（离训练集最近邻多远）：$u_i^2 = \min_{\phi_j\in\Phi_\text{train}} \lVert \phi_i - \phi_j\rVert_2^2$。
- **后验型**（就是 §4.3 的杠杆，贝叶斯线性回归的预测方差）：$u_i^2 = \phi_i^\top A^{-1}\phi_i$。

由于 $\phi$ 维度等于参数量，常用\*\*随机投影或草图化（sketching）\*\*降维，即用随机矩阵 $U$ 把高维特征映射为 $\phi^\text{rp} = U\phi$。Johnson–Lindenstrauss 引理可在有限点集上近似保持欧氏距离，但它不自动保证含矩阵求逆的后验二次型和选点排序不变；实际维度应通过子空间嵌入误差和选点一致性实验确定。

### 8.2 优势与适用边界

**优势**：只需一个基础模型；在线性高斯近似下可得到闭式后验；最后一层能量版本可直接使用 SeZM 的 `structural_feature`。Zaverkin、Holzmüller、Kästner 等已系统研究梯度特征与草图化 NTK 的批量主动学习；Varga-Umbrich、Weller-Davies、Duckworth 等在 2026 年进一步提出力感知 NTK，通过参数—坐标混合导数构造能量—力联合核，并在约 20 万个候选上验证了分块短名单策略。

**局限**：只使用点态后验方差时，它仍然主要回答"新颖性"；距离型指标还会对异常点敏感。批量去冗余和目标条件化需要额外设计。若候选池本身就是目标分布的样本，基于信息矩阵的批量主动学习（Batch Active learning via Information maTrices, BAIT）和期望预测信息增益（Expected Predictive Information Gain, EPIG）等方法已经部分包含代表性，不能简单归类为"完全缺失部署信息"。

## 9. Laplace 后验近似

§8 的"后验方差"有一个更规范的来历，它同时说明了为什么在 $\theta^\star$ 附近的线性化是合法的。

**Laplace 近似**在最大后验点 $\theta_\text{MAP}$ 附近用高斯分布近似参数后验，其协方差由选定的曲率近似——例如完整 Hessian、GGN、Fisher 或 Kronecker 分解曲率近似（Kronecker-factored approximate curvature, K-FAC）——之逆给出。进一步把网络在 $\theta_\text{MAP}$ 处线性化，可得到贝叶斯广义线性模型；在固定特征与高斯似然下，其预测方差为 $\phi^\top A^{-1}\phi$。这里的"精确"只针对线性化后的概率模型，不代表原非线性网络的真实后验被精确恢复。

**最后一层 Laplace（last-layer Laplace）** 只对最后一层做贝叶斯处理，并固定前面的特征提取器。此时预测方差就是最后一层特征的二次型，计算成本较低；代价是忽略骨干网络的不确定性。`structural_feature` 可支持最终能量输出权重的最后一层 Laplace 原型，但不能代表 SeZM 全部 LoRA 微调参数的后验。

## 10. 影响函数与 Cook 距离：一个点"改变了多少"

前面的不确定性都在问"模型对这点有多没把握"。还有一个正交的角度：**这个点一旦加入训练集，会把模型改变多少？** 这就是经典统计学的\*\*影响函数（influence function）\*\*与 **Cook 距离**。

以线性回归为例，若删除或加入某个样本会明显改变拟合参数，该样本就具有较高影响。Cook 距离把这种变化量化为标量，在经典线性模型中与**杠杆 × 残差²**相关，从而同时反映样本几何位置与当前拟合误差。

近期工作（Baghishov 等，2025）把它推广成 MLIP 训练集缩减的**加合性 Cook 距离（Additive Cook's Distance）**：定量评估"某构型加入训练集后，对模型预测与参数估计的边际影响"，并用它做**逐步数据选择**——不需要每加一个点就大规模重训，而是用闭式影响估计快速排序，识别信息密度最高、对泛化最关键的子集。

**评价**：影响函数与 §4.3 的杠杆在同一线性化下相关，优点是自然融合残差信息，缺点是仍然缺少目标条件化，并且对异常标签敏感。完整的样本价值还需同时考虑目标代表性和标签可信度。

## 11. 校准与共形预测：让不确定性可比较、可信赖

许多方法给出的不确定性首先只是相对分数，可用于排序，但未必对应真实误差的单位和尺度。\*\*校准（calibration）\*\*用于建立分数与实际误差之间的定量关系，使停止或标注阈值具有可解释性。

**共形预测（conformal prediction, CP）** 是一种模型无关的区间校准框架。基本做法是：留出不参与训练的**校准集**；为每个校准样本计算预测误差或归一化误差，称为不符合度分数；取这些分数的经验 $(1-\alpha)$ 分位数 $q$；再用 $q$ 构造新样本的预测区间。在校准样本与测试样本满足可交换性时，共形预测提供有限样本的边际覆盖保证：预测区间覆盖真值的概率至少为 $1-\alpha$。该保证不自动覆盖分布偏移或条件覆盖。

在 MLIP 里，已有工作把 CP 与神经网络**隐空间距离**结合，在百万级数据上得到既校准又"锐利"（区间不过宽）的能量不确定性；更晚近的工作用**环境相关的柔性校准**（每个原子环境有自己的自适应区间），改善了不确定性—误差相关性。**对采样的意义**：校准决定了绝对阈值能否解释为误差界。拟议框架主要使用相对排序，但 DFT 停机、安全阈值和收敛概率仍需独立校准；共形覆盖保证还依赖校准集与测试样本的可交换性，分布偏移时不能直接沿用。

## 12. 无模型信息熵与冗余度量

前面的方法都需要训练好的模型。另一类方法只使用数据表示本身，用于评估数据集冗余和样本新颖性，是数据清洗与压缩的重要工具。

### 12.1 QUESTS：信息熵与惊讶度

QUESTS（Quick Uncertainty and Entropy via STructural Similarity）用一个基于 k 近邻距离的快速结构描述子，结合 §4.5 的 KDE，得到数据集的**信息熵** $\mathcal{H}$（多样性与可压缩性的代理）和单点的**微分熵/惊讶度** $\delta\mathcal{H}$（衡量相对于指定参考集的新颖性）。其作者报告 150 万个原子环境在 56 线程上约 3 秒完成，并展示了 $\delta\mathcal{H}$ 与部分数据集力误差的经验相关性，以及主动学习后期的高冗余。这些结果依赖描述子、带宽、参考集规模和任务；$\delta\mathcal{H}>0$ 不是跨体系通用的物理外推判据。

### 12.2 三个实用的冗余度量指标

系统比较不同数据源的可压缩性，需要从多个角度量化冗余：

- **本征维度估计（intrinsic dimension）**：数据虽然嵌在高维描述子空间，但往往实际只"占据"了一个低维流形（想象一张纸揉进三维空间，它本征上还是二维的）。本征维度就是这个"真实自由度个数"。本征维度越低，说明数据被少数几个方向主导、冗余越高、越好压。
- **k 近邻（k-nearest neighbors, KNN）相似度分布**：对每个样本计算它到第 $k$ 个最近邻的距离。若大量样本的最近邻距离很小，说明局部高密度冗余较强；若分布较分散，说明覆盖更均匀。
- **基于聚类的压缩比**：把数据聚成若干簇，看"多少个簇能覆盖大部分样本"。少数簇就装下大部分点 = 高冗余。

这些指标主要用于诊断数据密度、冗余和压缩风险，而不是直接给出无损压缩率。它们把 §2.1 中"生成方式—冗余特征"的关系转化为可测量量，可用于设置分层筛选的候选预算。

### 12.3 最小集合覆盖：把"去冗余"写成一个干净的优化

Yu 等（2025）把数据压缩形式化为**最小集合覆盖（Minimum Set Cover, MSC）**问题。集合覆盖是个经典问题：给定很多"集合"，要用**最少数量**的集合把所有元素都覆盖到（想象用最少的圆盖住地图上所有城市）。搬到原子数据：每个结构"覆盖"它包含的那些局域原子环境（在特征空间某半径内），目标是选最少的结构，使**所有**出现过的局域环境都被至少覆盖一次。

这个表述会优先保护覆盖次数少的环境，因此适合保留结构长尾；但它同样可能保护量化噪声和异常点，必须与数据质量审计联合使用。Yu、Lordi、Schwalbe-Koda 等的工作把压缩写成最小集合覆盖，并在其实验中较好地保留了力分布长尾。§22 的覆盖记账是对这一思路的流式近似，不继承原组合优化的最优性保证。

## 13. 随机采样为何是重要基线

若候选池本身接近目标分布，随机采样会自然保持该分布，因此是所有主动采样方法都应比较的基线。主动方法不一定稳定优于随机，主要有以下原因：

1. **随机采样可保持候选池密度。** 如果候选池本身来自部署分布，随机采样得到的经验分布也会近似 $\rho_\text{deploy}$。聚类、最远点采样和 D-最优会重新分配不同密度区域的权重，因此可能降低对高概率区域的拟合质量。

1. **高维、小预算场景下，不确定性采样可能不如均匀采样。** 相关理论与实验表明，即使不确定性估计准确，边界优先的采样也可能牺牲对主体分布的拟合。

1. **模型失配时不确定性采样可能失效。** 偏差—方差分析表明：当模型类无法表达真值、偏差主导误差时，基于预测方差的主动学习不再保证优于随机。实际 MLIP 通常都存在不同程度的模型失配。

1. **校准不充分会削弱 UQ 的选点价值。** 一些基准发现，不确定性分数与真实误差的排序相关较弱；仅缩放分数尺度并不能修正排序方向。

1. **逐点精度不等于采样分布正确。** 近期研究显示，用标准均方误差训练的势即使在留出 DFT 测试集上达到较低误差，作为采样器仍可能进入虚假低能极小值，使热力学量偏离参考结果。因此，采样设计还应评估目标系综上的轨迹与物性误差，而不能只看候选池上的逐点误差。

**这些结果给出几条设计原则**：

- **应显式考虑代表性或部署分布**，否则很容易输给随机基线。
- **不确定性应与部署权重、批量冗余和标签质量联合考虑。**
- **优先单模型、少调参、可扩展的方法**，并把特征提取与调参成本计入总预算。
- **利用 MLIP 的物理结构**，包括力、对称性、能量守恒和势能面曲率。

文献中多样性或主动学习相对强随机基线的增益通常依赖候选池冗余度、模型设定和标注预算。部分工作报告以少约 5%–15% 的标注量达到相近精度，这不代表所有任务都能获得相同收益。高冗余轨迹和窄目标微调是更可能受益的场景。

## 15. 选点：给定候选池，标注哪些

### 15.1 不确定性驱动

DPGEN 的模型分歧指标（§7）、单模型梯度后验（§8）和 Cook 距离（§10）已在前文详述。以下介绍与它们相关的最优实验设计方法。

### 15.2 D-最优 / MaxVol 外推度（MTP、ACE / pacemaker）

**方法原理。** 对参数线性的模型——例如矩张量势（moment tensor potential, MTP）和线性原子团簇展开（atomic cluster expansion, ACE）——梯度特征就是基函数向量。MaxVol 维护一个**活跃集**：从训练集中选择 $n$ 个特征行组成方阵 $X_\text{active}$，使 $\lvert\det(X_\text{active})\rvert$ 尽可能大。对新构型 $x$，定义

```math
\gamma(x)=\max_j|c_j|,
\qquad
(c_1,\ldots,c_n)=\phi(x)^\top X_\text{active}^{-1}.
```

$\gamma>1$ 表示用新构型替换活跃集某一行可扩大特征体积，因此被解释为外推。分子动力学中可在 $\gamma$ 超过阈值时暂停、标注并更新活跃集。

**优势。** 具有明确的 D-最优设计基础；计算成本低于多模型集成；$\gamma$ 具有几何解释；MaxVol 会抑制基函数空间中冗余的活跃集行。

**适用边界。** D-最优偏好扩大参数信息体积的构型，而部署目标未必依赖这些方向；MTP / ACE 满足参数线性条件，深度图神经网络（graph neural network, GNN）则需要局部线性化；外推度本身也不区分标签噪声。从 MaxVol 推广到非线性微调子空间与目标量 Fisher，已属于 I/V-optimal、BAIT/EPIG 和 information-matching 等已有研究路线；第五部分只讨论 SeZM 实例化。

### 15.3 高斯过程后验方差（FLARE / 稀疏高斯过程）

**方法原理。** 高斯过程（Gaussian process, GP）为函数建立概率分布，可同时输出预测均值与后验方差。FLARE 在分子动力学的每一步计算不确定性；超过阈值时调用 DFT 并把原子环境加入稀疏训练集，否则继续运行。

**优势。** 概率模型与后验方差定义一致，适合在线稀有事件学习。

**适用边界。** 精确 GP 的训练复杂度通常为 $O(N^3)$，大数据必须使用稀疏近似；核函数和稀疏化都会影响校准与表达力。第五部分使用相似的后验方差数学，但不继承 GP 的概率正确性。

### 15.4 证据学习 / MC-Dropout（单次前向 UQ）

**方法原理。** 证据深度学习让网络预测概率分布的参数，一次前向传播即可得到均值与方差；蒙特卡洛 Dropout（Monte Carlo Dropout, MC-Dropout）在推理时保留随机失活层，多次前向传播后用预测波动估计不确定性；均值—方差网络则直接预测均值和标准差 $\sigma$。

**优势。** 不需要独立训练多个模型，适合低成本初筛。

**适用边界。** 系统基准显示其校准质量依赖数据密度和分布偏移，在稀疏区可能失准，因此不宜作为唯一选点准则。

### 15.5 多样性驱动：FPS / CUR / core-set / DPP

这一族都在描述子空间做"几何覆盖"，无监督、不需要标签。

- **最远点采样（farthest point sampling, FPS）**：每次选择到已选集合最小距离最大的点，以贪心方式扩大覆盖范围。该方法去冗余能力强，但容易偏向边界和离群点，并可能低估高密度平衡区域的重要性。一种按力范数加权的 FPS 改进方法（文献中记作 GGFPS）用监督信号修正了部分问题。

- **CUR 分解**：奇异值分解（singular value decomposition, SVD）把矩阵分解为若干主要方向；由奇异向量得到的**杠杆分数**衡量样本对主子空间的贡献。CUR 据此选择代表性的行或列，PCov-CUR 进一步纳入目标属性。其局限与 D-最优类似：高方差方向不一定与部署目标一致。

- **核心集（core-set）与 k-center**：核心集方法希望用小子集近似全集训练效果。Sener 和 Savarese 在给定假设下把损失上界转化为 k-center 问题：选择 $k$ 个中心，使任意样本到最近中心的最大距离最小。其贪心算法具有 2-近似保证，但保证针对几何覆盖问题，不代表对任意 MLIP 风险都成立。

- **行列式点过程（determinantal point process, DPP）**：DPP 为候选子集定义概率，概率正比于核矩阵子块的行列式 $\det(L_Y)$。几何上，行列式对应特征向量张成的体积，相似点共同出现会压低体积。核可分解为质量项与相似度项，2026 年已有工作将 DPP 用于 HfO2 标注子集选择。DPP、D-optimal design 和对数行列式信息增益都使用行列式，但一般的逆迹 Woodbury 选择不是 DPP 的严格特例，也没有相同的次模保证。

### 15.6 批量信息论：BADGE / BAIT / BatchBALD

批量主动学习需要同时考虑单点信息量和批内冗余，BADGE、BatchBALD 和 BAIT 分别从梯度嵌入、联合互信息和 Fisher 信息矩阵出发处理这两个因素。

- **BADGE**：多样梯度嵌入批量主动学习（Batch Active learning by Diverse Gradient Embeddings, BADGE）在最后一层梯度嵌入上使用 k-means++ 聚类初始化。k-means++ 以距离加权方式选择初始中心，使中心更分散；梯度长度提供不确定性信号，方向提供样本差异信号，从而兼顾单点信息与批内多样性。
- **BatchBALD**：BALD 用预测与贝叶斯参数后验之间的互信息度量单点信息量，实践中常用 MC Dropout 或后验样本近似；普通深度集成分歧只是相关代理。只取单点 BALD 分数最高的一批会产生信息重叠。BatchBALD 改为计算**整批的联合互信息**。其目标在相应贝叶斯设定下具有**次模性**：已选集合越大，同一新样本带来的边际收益越小，因此贪心有 $1-1/e$ 近似保证。这个保证属于 BatchBALD 的互信息目标，不能迁移到 §24 的逆迹风险。
- **BAIT**：用 Fisher 信息矩阵选择批次，近似最小化选点后的预测不确定性。相关工作将 BADGE、BAIT 与期望信息增益联系起来，但这些联系依赖具体近似条件。

**与本文关系。** BADGE、BatchBALD、BAIT 与 EPIG 提供成熟的批量主动学习基线。BAIT / EPIG 已能使用目标池定义预测风险；若目标池独立同分布地来自部署分布，其经验 Fisher 就是 $M_\text{deploy}$ 的估计。因此第五部分的差异应限定为 SeZM 参数子空间、能量—力联合噪声、独立部署参考集与物理数据审计的具体组合，而不能表述为首次加入部署分布。

### 15.7 代表性驱动：DIRECT 分层聚类（M3GNet / MatPES 用）

**方法原理。** DIRECT 先用预训练模型编码结构，再用主成分分析（principal component analysis, PCA）把高维特征投影到较少的主要方向，随后用 BIRCH 这一适合增量大数据的层次聚类算法形成多个簇，最后在每个簇中分层抽样。MatPES 使用两阶段 DIRECT，从 2.81 亿个 MD 快照中选择约 43 万条 PBE 和 39 万条 r²SCAN 计算，并在簇内优先选择原子数较少的结构以降低 DFT 成本。

**优势与适用边界。** DIRECT 可处理较大候选池，并通过聚类与分层抽样控制输入覆盖。输入多样性不等于模型误差多样性，簇粒度与 PCA 维度仍需验证；第五部分因此把 DIRECT 作为粗筛基线，而非默认最优方案。

## 16. 探索：候选构型从哪来

§15 假设候选池已给定，本节讨论如何生成候选构型。分子动力学常见系综包括 NVT（固定粒子数、体积和温度）与 NPT（固定粒子数、压力和温度）；不同系综对应不同部署分布。

### 16.1 热扰动：高温 MD / NPT / 随机位移扰动

**方法原理。** 通过升温、加压和随机位移把体系推离平衡。随机位移扰动（rattle）通常为每个原子叠加独立的随机位移，并可同时扰动晶胞。OMat24 使用 rattle 加 Boltzmann 型筛选、短程第一性原理分子动力学（ab initio molecular dynamics, AIMD）以及扰动结构弛豫。

**优势与适用边界。** 该方法简单、易并行，并能覆盖非平衡构型。较大随机位移会提高近距离与高力构型的比例；较大 AIMD 时间步会改变访问分布和积分精度；代理模型筛选会把其偏差带入候选分布。这些构型不因此自动成为错误标签——只要对应单点 DFT 严格收敛，它们仍可能是合法高能训练数据。标签审计应区分采样分布偏差与 DFT 数值错误。

### 16.2 增强采样：metadynamics

**方法原理。** 元动力学（metadynamics）沿预设的\*\*集体变量（collective variable, CV）\*\*加入历史相关偏置势，推动体系越过自由能垒，从而采到过渡态或相变附近的稀有构型。

**优势与适用边界。** 元动力学可提高稀有事件采样效率，但结果依赖集体变量是否覆盖相关慢自由度；CV 通常需要体系知识。

### 16.3 不确定性偏置动力学：HAL、UDD 与偏置 MD

**方法原理。** 这类方法把不确定性 $u(x)$ 转换成偏置势，使 MD 更频繁地访问高不确定性区域。代表工作包括超活跃学习（Hyperactive Learning, HAL）、Kulichenko 等提出的不确定性驱动动力学（uncertainty-driven dynamics, UDD），以及 Zaverkin 等基于梯度不确定性的偏置 MD。后者还利用自动微分构造偏置应力，以探索晶胞自由度。

**优势与适用边界。** 与无差别升温相比，不确定性偏置可更集中地探索模型弱区，也不要求预设 CV。若不确定性未校准，偏置可能把体系推向非物理区域；偏置强度与安全约束都需要标定。§26 在 HAL、UDD 和 Zaverkin 等工作的基础上讨论尚待验证的目标条件化偏置。

### 16.4 逆向生成：对抗攻击采样

**方法原理。** 对抗式采样把坐标视为可优化变量，通过梯度上升增大经物理似然加权的不确定性目标，从而生成模型薄弱区域的候选。

**优势与适用边界。** 它不依赖长时间轨迹，但高度依赖不确定性函数与物理约束的质量，也可能产生无法稳定计算或实际不可达的构型。

## 17. 数据压缩与标签质量审计（对应任务①④）

### 17.1 冗余剪枝（coreset / 熵去重 / MSC / 嵌入去重）

**方法原理。** 用 FPS、CUR、核心集、QUESTS、最小集合覆盖（MSC）或嵌入近邻构造压缩子集。QUESTS 信息熵可描述特定表示与带宽下的数据多样性，但不能直接给出任意模型的无损压缩率。SOAP+FPS 在 Li–Si 数据上、局域环境选择在若干中小体系上报告过较高压缩率并保持模型性能。

**适用边界。** 压缩结果依赖数据集与模型；无监督去重可能删除稀有但真实的构型，也不会自动发现错误标签。

### 17.2 难度剪枝与标度律（Sorscher, "Beyond neural scaling laws"）

**做法与关键洞察。** 给每个样本打**难度分**，按预算决定删易还是删难。Sorscher 等在特定 teacher–student 感知机理论与图像数据实验中发现：数据少时典型 / 易样本更重要，数据多时难样本更可能保留精细结构；理想剪枝度量在这些设定中可改善幂律标度。这个结论尚不能直接作为 MLIP 数据剪枝定理。

**对 MLIP 的可迁移假设。** 数据清洗不应只设固定压缩率，可以比较预算相关的"典型样本优先"和"高信息样本优先"两种策略。迁移是否成立必须由学习曲线与 MD 稳定性验证；难度分若被异常标签污染，"保留难例"会退化为保留标签错误，因此应先完成 §17.3 的标签审计。

### 17.3 标签质量审计：物理一致性 / 置信学习 / 交叉拟合残差

**目标**：识别值得复算、隔离或降权的可疑标签，而不是用单一启发式直接删除。对主流分子数据集的净力审计显示，不同数据源的标签一致性差异可达到与模型力误差同量级；这说明标签噪声可能成为精度地板。三类互补的检测手段：

- **物理一致性检查**：
  - **净力**：在无外场、无约束、包含全部原子且哈密顿量平移不变的封闭体系中，总力应接近零。$\lvert\sum_i \mathbf{F}_i\rvert / \sum_i \lvert\mathbf{F}_i\rvert$ 可作为可疑信号；外场、量子力学/分子力学耦合（QM/MM）、固定原子、只保存子系统以及分母很小时都可能产生假阳性。成对抵消的错误还会造成假阴性。

  - **组成基线残差与内聚能**：内聚能的符号约定必须先固定，孤立原子参考还依赖自旋、荷电、赝势、泛函和有限盒设置。Huber 回归是一种降低离群点影响的稳健回归；逐元素 Huber 回归得到的是数据集依赖的组成基线残差，不是严格内聚能。高温、碰撞、解离或刻意加入的排斥构型可能合法地高于孤立原子极限，因此这类指标只能标记异常，不能直接删除。

  - **能量—力路径积分一致性**：对同一轨迹的相邻帧，可检查

    ```math
    \left|E_2-E_1+\tfrac12(\mathbf{F}_1+\mathbf{F}_2)\cdot(\mathbf{R}_2-\mathbf{R}_1)\right|.
    ```

    该式是 $\mathbf{F}=-\nabla E$ 的梯形积分近似。使用时必须保证原子对应关系与周期性边界条件（periodic boundary condition, PBC）的展开正确，容差随位移和局部曲率变化；变胞轨迹还要加入应力—应变功。高曲率、大步长和合法的电子态切换都可能产生假阳性。

  - **应力—能量一致性、极端受力、最短距离**等也只用于筛查。Ziegler–Biersack–Littmark（ZBL）势描述极短程核间排斥，不应把所有超出其经验包络的高能碰撞帧都视为错误。
- **置信学习与回归标签审计**：Northcutt、Jiang、Chuang 的 confident learning 主要针对分类标签；连续能量/力应使用专门的回归标签审计、稳健似然或复算校准，不能直接套用分类的噪声联合分布结论。
- **交叉拟合残差**：K 折训练代理模型，对每点计算样本外残差。数据必须按轨迹、材料原型、组成和来源做**分组划分（group split）**，避免同一轨迹的相邻帧同时进入训练与验证而低估残差。

**覆盖度与残差只能联合形成筛查象限，不能自动完成消歧。** $\delta\mathcal{H}\le 0$ 且高残差可能来自异常标签，也可能来自模型欠表达、多值电子态或遗漏的全局变量；$\delta\mathcal{H}>0$ 且高残差既可能是难例，也可能是孤立异常点。合理流程是按象限分层抽样，用统一且更严格的 DFT 设置复算一小批，估计各象限的**标签可信概率** $p_\text{clean}$，再决定删除、隔离或降权。

### 17.4 质量优先的案例证据（MatPES）

MatPES 使用严格收敛的静态 DFT 与分层采样构造约 43 万条数据，并在其报告的若干模型与基准上与更大数据集竞争；MAD-1.5 则用统一的全电子 r²SCAN 工作流构建紧凑的跨元素数据集。这些案例支持"系统研究数据质量与冗余，而非只扩张规模"的方向，但不能单独证明清洗后的 OMat24 必然优于原数据：DFT 理论层级、候选空间、模型架构和评测集均可能造成差异。任务①应通过同模型、同训练机时、同评测协议的压缩曲线验证。

## 18. 蒸馏与快速生产：低成本教师标签的利用（对应任务②③）

### 18.1 在线策略师生蒸馏（DPA-2 / PFD）

**方法原理。** 预训练—微调—蒸馏（pre-training, fine-tuning, and distillation, PFD）流程先把基础模型微调为教师，再由教师为目标体系生成合成标签，训练更轻量的学生模型。在线策略版本还会让学生运行目标轨迹，并把师生分歧较大的构型加入训练集。Wang、Gao、Wu 和 Zhong 的 PFD 工作报告了材料特定势函数生产中的数据与推理效率改进。

**优势与适用边界。** 教师前向远低于 DFT 成本，可生成大量合成标签；学生轨迹能够暴露学生自身诱导的分布漂移。但师生分歧不等于真实误差，教师系统性错误会传递给学生，一轮教师分布蒸馏也未必覆盖学生轨迹。§29.3 因此把师生分歧、学生后验和学生覆盖分别作为待比较基线。

### 18.2 Hessian 蒸馏（Amin, Raja, Krishnapriyan, ICLR 2025）

**方法原理。** Amin、Raja、Krishnapriyan 在 ICLR 2025 提出 Hessian 蒸馏，使学生同时匹配教师的能量、力与部分 Hessian 行。Rodriguez、Smith、Matin、Lubbers、Barros、Mendoza-Cortes 在 2026 年进一步提出投影 Hessian 学习（Projected Hessian Learning, PHL），用随机 Hessian—向量积（Hessian-vector product, HVP）替代完整 Hessian 监督，并报告了训练加速。SeZM 的二阶反向传播为 HVP 实验提供基础，但具体 HVP 蒸馏路径仍需单独实现和验证。

### 18.3 合成数据预训练 与 Δ-learning

**合成预训练**（Gardner & Deringer）：先用一个已有 MLIP 大量生成"合成"标签，让学生在海量合成数据上预训练学到物理表征，再用少量真 DFT 微调。低数据场景提升精度与稳定性，但学生精度上限受教师限制。

**Δ-learning**（Ramakrishnan、Dral、Rupp、von Lilienfeld）：不直接学高精度目标，而是学低精度基线与高精度目标之差 $\Delta$，预测时 $y=y_\text{baseline}+\Delta_\text{model}$。当两个理论层级强相关时，$\Delta$ 往往比绝对目标更易学习；这不是普适保证。若把 OMat24 等数据当作低层级基线，还必须保证基线预测在推理时可获得，并用同构型、同电子态的高层级配对标签训练，不能把未收敛标签直接包装成 Δ-learning。微调也可被理解为学习参数空间修正，但所需数据量必须按具体任务实测。

### 18.4 DAgger 对在线策略迭代的启发

§4.6 已说明 DAgger 的原始保证不能直接移植到 MLIP。对任务②③，更准确的表述是：**候选池应包含当前模型或当前学生在部署条件下访问的轨迹，并随模型更新迭代刷新。** 这是受 DAgger 启发的抗分布漂移策略，其收益需要通过 MD 稳定性和目标物性实验验证。

# 第四部分　统一视角

## 19. 两种一致的价值写法

不同方法可以放进同一决策框架比较，但不能把它们都说成某个公式的严格特例。尤其需要避免把部署分布重复计算两次。

### 19.1 未目标条件化的局部价值

若边际信息增益 $\Delta_\text{local}(x\mid\mathcal{S})$ 本身不含部署分布，那么可以写成启发式的局部价值：

```math
a_\text{local}(x)
\;\propto\;
\rho_\text{deploy}(x)\,
\Delta_\text{local}(x\mid\mathcal{S})\,
\frac{\operatorname{SNR}_\text{label}(x)}
{\operatorname{cost}_\text{DFT}(x)}.
```

其中 $\operatorname{SNR}_\text{label}(x)$ 是标签信噪比（signal-to-noise ratio）：可学习物理信号方差与标签误差方差之比，是无量纲的质量因子；$\operatorname{cost}_\text{DFT}(x)$ 是预期标注机时。实际应用中若缺乏复算数据，信噪比通常无法可靠估计，此时应把标签噪声统一放入 §24 的观测协方差 $R_c$，而不是单独使用该因子。

随机采样主要保留了 $\rho_\text{deploy}$；点态后验方差、模型分歧指标和距离新颖性主要刻画 $\Delta_\text{local}$ 的某个代理；成本与标签质量则需要另外建模。这个乘积是决策启发，不是由统一概率模型自动推出的定理。

### 19.2 已目标条件化的风险下降

若目标已经定义为

```math
R_\text{var}(\mathcal{S})
=
\operatorname{tr}\!\left(\Sigma_\mathcal{S}M_\text{deploy}\right),
```

其中 $M_\text{deploy}$ 已经对 $\rho_\text{deploy}$ 取期望，那么边际下降

```math
\Delta_M(x\mid\mathcal{S})
=
R_\text{var}(\mathcal{S})
-
R_\text{var}(\mathcal{S}\cup\{x\})
```

已经包含部署代表性，**不能再额外乘一次 $\rho_\text{deploy}(x)$**。第五部分采用这一写法。它只优化 §1.3 中的认知方差项，不能处理所有模型成员一致地犯下的系统性错误。

### 19.3 与现有方法的关系

- DPGEN、深度集成、GP 方差与梯度后验都提供认知不确定性的不同近似，但不彼此严格等价。
- MaxVol / D-最优设计优化参数信息体积；A/I/V-最优设计优化迹形式的平均方差；二者目标不同。
- FPS、core-set、DIRECT 与 DPP 在表示空间控制覆盖或批量多样性，它们不是 Fisher 方法的代数退化。
- Ash 等的 BAIT、Kirsch 等对 EPIG / Fisher 方法的统一分析，已经把候选池或目标池的预测风险纳入批量主动学习；若候选池独立同分布地来自部署分布，候选池 Fisher 本身就是部署 Fisher 的经验估计。
- Kurniawan、Neilsen、Francis 等提出信息匹配最优实验设计（information-matching optimal experimental design, information-matching OED），用目标量（quantity of interest, QoI）的 Fisher 信息约束训练数据；Kurniawan、Williams、Samanta 等随后将它用于针对金属塑性强度的专用原子势。目标条件化 Fisher 设计因此属于已有研究路线。
- QUESTS 的 KDE 惊讶度、最小集合覆盖和 DPP 与 Fisher 后验具有相似的“新颖性 / 去冗余”目的，但不能通过简单设 $M=I$ 就变成同一个算法。

# 第五部分　目标感知分层采样框架

## 21. 总体思想与创新边界

单一算法难以同时满足"上亿条数据上的可扩展粗筛"和"模型 / 部署感知的精细选择"。本部分因此组织一个由粗到细的四层研究框架：

1. **可扩展粗筛层（§22）**：用已有的原子环境离散化、加权 MinHash、近邻索引和集合覆盖思想建立流式短名单。
1. **物理审计层（§23）**：把物理一致性规则作为疑点标记，经统一 DFT 复算校准后估计标签可信度。
1. **目标感知实验设计层（§24）**：在独立部署参考集上定义目标风险，用线性化能量—力联合观测估计边际方差下降。
1. **跨领域训练层（§25）**：保持异构 DFT 任务边界，并将样本选择与 SGD 任务权重分别建模。

各组成思想均有明确先例，详细归属见 §27：最优实验设计与信息匹配负责目标条件化，BAIT / EPIG 负责 Fisher 批量选择，力感知 NTK 提供能量—力联合特征，QUESTS / MSC 提供环境覆盖与压缩工具，大语言模型（large language model, LLM）数据工程提供近重复检测，EWC 与在线 Laplace 提供预训练曲率先验。可检验的潜在贡献限定为：

- 在统一噪声模型下把独立部署参考集、SeZM 可训练参数子空间与能量—力联合 Woodbury 更新连接起来；
- 将原子级稀有环境覆盖账本与异构 DFT 任务边界组合为可扩展数据管线；
- 在不高估现有高阶导能力的前提下，验证目标条件化风险下降能否用于安全偏置探索。

下面逐层展开。

## 22. 第一层：原子环境"词表"与覆盖记账（可扩展粗筛）

面对上亿条结构，逐样本梯度并不现实。粗筛层只使用一次流式特征提取与离散索引，把候选规模降到后续模型感知方法可以处理的范围。

### 22.1 核心类比：原子环境之于结构，正如词之于文档

一篇文档可以表示成词频多重集；一个原子结构也可以表示成局域原子环境的多重集。把连续原子环境量化成离散码字后，可以借用文本近重复检测的索引技术。但原子结构具有元素、周期边界、长程电荷、电子态和 DFT 任务等文本数据没有的约束，因而只能迁移数据结构，不能直接迁移删除规则。

### 22.2 把连续环境离散成"词表"：码本量化

**相关工作。** Xia 等的 MOLE-BERT 已用上下文感知的向量量化变分自编码器（vector-quantized variational autoencoder, VQ-VAE）把原子局域环境离散成词元；AtomDisc（2025）把局域环境量化为结构感知原子词元；Takayuki Kimura 的 VQ-Atom（2026）进一步提出局域化学环境的语义离散。

**用于数据粗筛的实例化。** 用冻结的 ACE 描述子或预训练大模型原子嵌入流式编码环境，在按中心元素、任务类型、荷电 / 自旋状态分层的代表性子样本上训练层次化码本。随后只保存码字编号与计数，不保存全库连续嵌入向量。码字数量、量化误差和分层方式必须由验证集决定；$10^4$–$10^6$ 只是可能范围，不能预先宣称某个规模可行。

百亿环境若各保存 128 维 32 位浮点向量，原始存储约为 5 TB；把每个环境精确分配到百万中心同样不可行。实际系统需要分层 k-means、倒排文件与乘积量化（inverted file / product quantization, IVF/PQ）或其他近似量化，并给出吞吐、召回率、峰值内存和端到端机时测试。上亿帧"天级完成"不是可直接假定的事实。

**逆文档频率（IDF）。** 定义码字的 IDF 为

```math
\operatorname{IDF}(k)
=
\log\frac{N_\text{structure}}
{n_{\text{structure containing code }k}}.
```

它可用于发现低频环境，但低频不等于高价值：量化误差、单位错误、非物理结构和异常标签也会得到高 IDF。IDF 只作为覆盖保护与人工审计的候选信号，不直接作为最终保留分数。

### 22.3 分级去重管线

分级粗筛按计算成本由低到高依次进行：

- **第 0 级：来源感知抽帧。** 对 MD / 弛豫轨迹按自相关时间、位移或目标物性变化抽帧。抽帧率是数据压缩参数，不能假定相邻帧都无价值。
- **第 1 级：精确 / 近精确结构哈希。** 使用 spglib 等工具识别原胞并标准化晶胞，再结合成分、分数坐标、周期性和数值容差构造哈希。Niggli reduction 只约化晶格基，**不能单独把 2×2×2 超胞识别成 1×1×1 原胞**。缺陷、部分占位和磁性还需要额外元数据，不能只靠几何哈希。
- **第 2 级：加权 MinHash 与局部敏感哈希。** Jaccard 相似度用集合交集与并集的比例衡量重叠；加权 Jaccard 则对直方图各维的较小值与较大值求和后取比值。原子码字直方图是多重集或加权向量，普通 MinHash 只适用于集合 Jaccard；应使用 Sergey Ioffe 提出的一致加权采样（consistent weighted sampling）或加权 MinHash 来近似加权 Jaccard。局部敏感哈希（locality-sensitive hashing, LSH）让相似样本更可能落入同一哈希桶，从而避免全量两两比较。常见体相环境可能形成超大桶，因此必须限制桶大小、二次分桶并报告召回率。
- **第 3 级：连续嵌入近邻。** Lee 等的近重复检测、Abbas 等的 SemDeDup、Tirumala 等的 D4 以及向量近邻检索库 FAISS 提供成熟索引工具。它们只负责产生相似候选，最终决策仍需覆盖与物理审计。
- **第 4 级：密度重分配。** DIRECT 由 Qi 等提出，用降维编码、BIRCH 聚类与分层抽样构建鲁棒训练集。是否对稠密区降采样取决于目标：保持原经验分布与主动均衡长尾是两个不同目标。

### 22.4 结构相似度与原子环境覆盖的粒度差异

平均池化可能淹没少量关键环境：一个含 1000 个体相原子和 1 个缺陷环境的结构，均值向量可能与纯体相结构很接近。因而结构相似度与原子环境覆盖应分开记账。

因此分别维护结构相似度与原子环境覆盖：

- **相似度轨**：用池化嵌入或码字直方图产生候选近重复对，不直接删除。
- **覆盖轨**：维护按元素 / 任务分层的码字计数，检查候选是否提供低覆盖环境。计数型布隆过滤器（counting Bloom filter）是一种节省内存的近似集合结构，但哈希碰撞会高估覆盖量，可能遗漏稀有环境；关键长尾应使用精确哈希表或保守的低频回退机制。

这相当于 Yu、Lordi、Schwalbe-Koda 等最小集合覆盖思想的流式近似，但没有最优性保证。低频码字只触发保守保留或复核；还应随机保留一小部分被判冗余的样本，用来估计码本碰撞与 LSH 漏检造成的偏差。

### 22.5 源自大语言模型数据工程的实践原则

- **保持原分布与密度均衡必须分开。** 若每个覆盖簇只保一个代表、但希望保持原经验分布，代表样本的训练权重应等于原簇样本数，或使用逆采样概率作重要性校正。给每个样本赋 $1/\text{局部密度}$ 会把各区域权重拉平，**不会保持 $\rho$**；它只适用于明确希望重平衡长尾的训练目标。
- **去重强度要在下游验证上标定，不能只看压缩率。** 大语言模型数据处理中常用小模型和验证损失扫描阈值；MLIP 可用代理模型的能量、力误差和 MD 稳定性共同标定，因为静态测试误差并不能充分预测轨迹稳定性。

### 22.6 跨数据集几何去重的任务边界

**跨数据集去重只能在几何 / 表示层面记账，不能因为局域环境重复就跨任务删除。** PBE 与 r²SCAN 是不同的 DFT 交换—关联泛函近似；它们与不同 Hubbard $U$、电荷或磁态都对应不同监督目标，并不存在一个普适的"标签精度更高者"。正确做法是保留任务标识，在各任务内部去重；共享骨干是否还需要同几何的多任务监督，应由跨任务验证决定。

**这一层的产出**：一个带有数据来源、任务、码字覆盖、近重复簇和原簇样本数的流式短名单。压缩倍率、吞吐和召回率都必须实测，不能预设一定降低一个数量级。

## 23. 第二层：物理筛查—统一复算—概率加权

物理规则只产生**疑点标记**，不直接决定删除。完整流程分四步：

1. **来源感知筛查。** 根据体系元数据决定哪些规则适用：净力只用于无外场、无约束、包含全部原子的封闭体系；最短距离与 ZBL 只标记短程碰撞；组成基线残差按元素、荷电、磁态与 DFT 任务分别建模。
1. **轨迹一致性筛查。** 对正确展开 PBC、原子一一对应且步长足够小的定胞轨迹，计算能量—力梯形残差；变胞轨迹加入应力—应变功。磁态或电子态改变的帧不与另一分支直接比较，而应拆分任务或复算。
1. **分层复算校准。** 按数据源、组成、疑点类型、QUESTS 惊讶度和交叉拟合残差分层抽样，用统一赝势、k 点、截断能和更严格的 SCF 设置复算。交叉拟合必须按轨迹或材料原型分组划分。
1. **概率加权。** 用复算结果估计标签可信概率 $p_\text{clean}(x,m)$，其中 $m$ 表示数据来源、DFT 设置、电子态等元数据。确认错误的样本才删除；证据不足的样本隔离或按标签可信概率使用稳健似然。高残差与 $\delta\mathcal{H}$ 只定义抽样象限，不自动把样本判成噪声或难例。

这一层的产出是：确认错误集、隔离复查集、带标签可信概率的保留集，以及各筛查规则的精确率（precision）和召回率（recall）。没有复算真值时，只能报告异常评分，不能把它称为标签正确性。

## 24. 第三层：目标感知贝叶斯实验设计原型

本节把工作名 **DEED-FIS**（Deployment-aware Error-reduction Experimental Design via Fisher Information Sketch）保留为 SeZM 原型的简称。其数学基础来自经典 I/V-最优设计、Ash 等的 BAIT、Kirsch 等对 EPIG 的 Fisher 解释、Kurniawan 等的信息匹配最优实验设计，以及基于信息匹配的主动学习（Active Learning by Information-Matching, ALIM）；能量—力联合特征则直接参考 Varga-Umbrich 等的力感知 NTK。

### 24.1 确定可训练参数子空间

实验设计中的特征必须与实际微调参数一致：

- **最终能量输出权重**：可直接用 `structural_feature`，并为偏置参数添加原子数或分类型计数。这个版本成本最低，但只描述输出头不确定性。
- **LoRA 与其他解冻参数**：必须对实际参数计算逐样本梯度草图（per-sample gradient sketch）。`structural_feature` 不能替代它。LoRA 的 $B$ 零初始化还会使初始 $\nabla_A E=0$，需要在参数化或预热更新后重新定义特征。
- **全模型参数**：梯度维数与计算成本最高，只适合短名单，不适合直接扫描上亿候选。

### 24.2 预训练曲率先验：已有 EWC / sequential Laplace 思路

Kirkpatrick 等的弹性权重巩固（Elastic Weight Consolidation, EWC）用旧任务 Fisher 约束新任务更新；Ritter、Botev、Barber 等的在线结构化 Laplace 用顺序 Laplace 传播近似后验。基础模型 Fisher 先验属于这条已有路线，可写成

```math
A_0=\lambda I+\kappa F_\text{pre},\qquad 0\le\kappa\le1.
```

$\kappa$ 是曲率缩放系数，用目标验证集校准基础模型曲率的可信度。只有在**同一参数化、同一似然、同一输出单位、未重复计入预训练数据**时，$F_\text{pre}$ 才能解释为顺序贝叶斯先验精度；否则它只是一个结构化正则矩阵。较大的 Fisher 也可能表示基础模型对错误函数过度自信，因此 $\kappa=1$ 不是默认选择。

### 24.3 部署方差目标

维护一个与候选生成相互独立的部署参考集

```math
\mathcal{T}=\{t_j\}_{j=1}^{N_T},\qquad t_j\sim\rho_\text{deploy}.
```

对部署输出构造白化雅可比矩阵 $G_t$。**白化**是按单位、噪声尺度或目标权重重新缩放不同输出，使能量、力和应力可在同一二次型中比较。$G_t$ 的行可以是每原子归一化能量、选定力分量、应力或目标物性对可训练参数的导数。部署二阶矩为

```math
M_\text{deploy}
=
\mathbb{E}_{t\sim\rho_\text{deploy}}\!\left[G_t^\top W_tG_t\right]
\approx
\frac1{N_T}\sum_{t\in\mathcal{T}}G_t^\top W_tG_t,
```

其中 $W_t$ 明确给出能量、力、应力和不同体系尺寸的权重。线性化后验协方差为 $\Sigma=A^{-1}$，目标方差代理为

```math
R_\text{var}=\operatorname{tr}(\Sigma M_\text{deploy}).
```

这个目标不包含模型偏差；独立部署集也仍可能受当前基础模型诱导分布的偏差影响。

### 24.4 标量特例与 MLIP 的向量 Woodbury 公式

对于固定特征的单个标量观测

```math
y_c=\phi_c^\top\theta+\epsilon_c,\qquad
\epsilon_c\sim\mathcal{N}(0,r_c),
```

Sherman–Morrison 公式用于在加入一个标量观测后高效更新矩阵逆，并给出精确的方差代理下降：

```math
\Delta_c^\text{scalar}
=
\frac{\phi_c^\top\Sigma M_\text{deploy}\Sigma\phi_c}
{r_c+\phi_c^\top\Sigma\phi_c}.
```

分子是候选预测与部署预测之间的**平方后验交叉协方差积分**；分母是包含观测噪声的候选后验预测方差。分母产生边际收益饱和，但不会普遍使“中等杠杆”优于“高杠杆”。一维情况下，该值随杠杆单调增加并趋于饱和；对无关极端点的抑制来自分子中的 $M_\text{deploy}$。

实际 MLIP 一帧同时提供能量、$3N$ 个力分量和可能的应力。令 $J_c\in\mathbb{R}^{m_c\times p}$ 为这些监督输出对可训练参数的联合雅可比矩阵，$R_c\in\mathbb{R}^{m_c\times m_c}$ 为按单位、任务和相关性定义的噪声协方差，则后验更新为

```math
\Sigma'
=
\Sigma
-
\Sigma J_c^\top
\left(R_c+J_c\Sigma J_c^\top\right)^{-1}
J_c\Sigma,
```

部署方差下降为

```math
\boxed{
\Delta_c
=
\operatorname{tr}\!\left[
M_\text{deploy}\Sigma J_c^\top
\left(R_c+J_c\Sigma J_c^\top\right)^{-1}
J_c\Sigma
\right].
}
```

Woodbury 公式用于在加入多维观测后更新矩阵逆；上式是其在后验协方差中的应用。标量 Sherman–Morrison 公式只是 $m_c=1$ 的特例。能量、力和应力不能共享一个未经白化的标量噪声。

### 24.5 标签可信度、收敛概率与成本

标签质量应优先进入 $R_c$ 或污染混合似然。例如根据 §23 复算校准得到的 $p_\text{clean}$，可用于放大可疑样本的有效噪声，或构造“可信标签—污染标签”混合分布。把一个独立的 $\tau(c)$ 直接乘在 $\Delta_c$ 外面，只能视为启发式。

对于尚未计算的 DFT 候选，可定义工程上的期望效用

```math
a(c)
=
\frac{P_\text{conv}(c)\,\Delta_c}
{\mathbb{E}[\operatorname{cost}_\text{DFT}(c)]}.
```

其中 $P_\text{conv}$ 表示 DFT 收敛概率，成本模型表示预期机时，二者必须由历史任务校准。DFT 失败仍然消耗机时，因此该式是工程效用函数，不是原 I-optimal 目标的严格边际增益。成本也不能只写成 $N^3N_k$：SCF 难度、真空、基组、并行效率、磁性和电子温度都可能主导实际机时。

### 24.6 候选池、部署参考集与选择流程

```
输入：
    当前模型与明确的可训练参数子空间
    独立无偏部署参考集 T
    候选池 P（可来自无偏 MD、偏置 MD、结构枚举等）
    已标注训练集 D、DFT 机时预算 B

1. 用 T 构造 M_deploy；禁止直接用偏置候选池 P 代替 T。
2. 用 D 与经缩放的先验 A0 构造 A、Σ=A^{-1}。
3. 先用低成本描述子或最后一层方差分块扫描 P，得到短名单 C。
4. 只对 C 计算与实际微调参数一致的能量—力雅可比草图。
5. 用向量 Woodbury 公式估计每个候选的 Δ_c，并结合校准后的成功率与成本排序。
6. 选择一个候选后更新 Σ，再重新计算剩余候选边际值；直到预算耗尽或验证风险进入平台。
```

一般 A/I-最优的逆迹方差缩减**不是次模函数**，因此没有普适的 $1-1/e$ 贪心保证，标准惰性贪心算法使用的旧边际值也不一定是安全上界。可选求解方式包括：

- 在短名单上精确重算的普通贪心；

- Ash 等 BAIT 的前向选择—反向剔除策略；

- Kurniawan 等信息匹配方法的凸优化松弛，即先允许候选具有连续权重，再由连续解恢复离散子集；

- 若必须获得次模保证，改用固定目标投影特征上的

  ```math
  F(S)=\log\det\!\left(I+\sum_{c\in S}z_cz_c^\top\right),
  ```

  但要明确它优化的是目标投影 D-最优代理，不是原逆迹风险。

### 24.7 力感知特征与计算成本

Varga-Umbrich、Weller-Davies、Duckworth、Tilly、Peltre、Surana 已在力感知 NTK（Force-Aware NTK）中用参数—坐标混合导数构造能量—力联合核，并通过分块后验方差短名单在约 20 万结构上验证了可扩展性。这里应直接以其方法为基线，而不是把力 NTK 声明为本文创新。

Hutchinson 探针满足

```math
\mathbb{E}_v
\left[(J_F^\top v)(J_F^\top v)^\top\right]
=
J_F^\top J_F
\quad\text{if}\quad
\mathbb{E}[vv^\top]=I,
```

Hutchinson 探针用随机向量估计大矩阵的迹或二阶矩。2–4 个探针虽然无偏，估计方差仍可能较大，局部稀有原子方向还可能被全局探针淹没。应先在低成本短名单上使用，并根据噪声权重对白化探针。`atomic_feature` 是隐藏激活，不是独立可观测的原子能标签，不能把每个原子直接当成独立 Fisher 观测。

若只使用最后一层激活，构造目标风险主要是矩阵运算；若使用 LoRA 或全梯度，则每个候选都需要反向传播或混合导数。形成 $M$ 通常需要 $O(N_Td^2)$，缓存短名单特征需要 $O(|C|d)$ 内存，选择 $B$ 个点的朴素重算约为 $O(B|C|d)$ 加矩阵更新。现阶段只能说矩阵部分可能可扩展，不能预先宣称“百万候选单卡分钟级”。

### 24.8 先做风险下降校准，再扩展系统

在构建大规模管线前，应先验证核心代理是否真的预测训练后的收益：

1. 从同一候选池分层随机取 50–200 个已做 DFT 的构型；

1. 对每个构型或小批次使用完全相同的微调协议；

1. 实测部署验证集下降

   ```math
   \Delta_\text{real}
   =
   R_\text{before}-R_\text{after};
   ```

1. 比较 $\Delta_\text{real}$ 与 $\widehat{\Delta}_c$ 的 Spearman 排序相关系数、校准误差和前 $k$ 项遗憾值；Spearman 系数衡量两个排序的一致程度，遗憾值表示所选前 $k$ 个样本的真实收益与理想前 $k$ 个样本收益之差；

1. 若相关性不显著，停止扩展并重新选择参数子空间、噪声模型或目标矩阵。

这个**前置证伪检查**应在构建百亿环境码本或偏置 MD 之前完成。

## 25. 第四层：跨领域多任务的联合筛选与动态权重

前三层处理"单一目标下的选点"。大原子模型（§2.4）同时使用多个数据集、服务多个下游领域，需要一个跨域扩展。这一层直接对应"跨领域数据整合"这一 LAM 时代的核心难题。

### 25.1 源内自适应筛选，再跨域联合

不同数据源的生成机制、冗余特征、信息密度和 DFT 任务定义差异巨大。因此先在每个**任务内部**做来源感知筛查，再用共享骨干验证跨任务互补性。各数据源的 $\delta\mathcal{H}$ 带宽、码本、噪声模型和可接受压缩率都可以不同。OMat24 轨迹是否比 OMol25 反应路径压缩得更多，应由实际冗余度与下游验证决定，而不是仅凭数据集名称预设。

### 25.2 多任务权重：让 Fisher 决定各数据集占多重

多任务训练里，各数据集的权重应由目标验证集反馈校准。但必须区分：

- **样本选择权重**：决定哪些结构进入训练集；
- **采样概率**：决定一个样本进入小批次（minibatch）的频率；
- **任务损失权重**：改变随机梯度下降（stochastic gradient descent, SGD）的优化目标与任务间梯度干涉。

三者不等价。Kendall 等的同方差不确定性加权、Chen 等的 GradNorm、Liu 等的动态权重平均（Dynamic Weight Average）已研究多任务损失加权；目标 Fisher 设计只能直接帮助样本选择，不能自动推出最优损失权重。

若为每个下游目标 $t$ 估计 $M^{(t)}$，可以用

```math
\sum_t w_t\,\operatorname{tr}\!\left(\Sigma M^{(t)}\right)
```

作为样本选择代理；$w_t$ 则应由独立验证集、双层优化（bilevel optimization，即外层调权重、内层训练模型）或预先声明的科学优先级确定。PBE、r²SCAN、不同 $U$ 值与不同磁态保留为独立任务，不按一个未经定义的"精度高低"合并。

### 25.3 基于模型反馈的动态校准

动态权重可以根据各目标的标准化验证损失、梯度冲突和风险下降效率调整，但它属于已有多任务优化路线。拟议框架只建议把数据源选择也纳入验证闭环：若某任务新增样本长期不能改善其目标验证风险，应降低该数据源的标注预算，而不是直接据此改变所有 SGD 损失权重。动态策略必须与固定权重、GradNorm 和不确定性加权等基线比较。

## 26. 候选生成：KL 正则的目标条件化偏置动力学

HAL、UDD 和 Zaverkin 等报告了不确定性偏置相对于无差别升温更快访问模型弱区的案例。本节讨论一个尚未验证的扩展：用 §24 的目标风险下降 $\widehat{\Delta}(x)$ 代替总不确定性。

仅最大化 $\mathbb{E}_q[\widehat{\Delta}]$ 会让 $q$ 集中到最大值点，不能推出平滑倾斜分布。Kullback–Leibler 散度（KL 散度）衡量一个概率分布相对于参考分布的偏离程度；加入相对于无偏参考分布 $\rho_\theta$ 的 KL 正则：

```math
\max_q\;
\mathbb{E}_{x\sim q}
\left[\log\!\left(\epsilon+\widehat{\Delta}(x)\right)\right]
-
\frac1\gamma
D_\mathrm{KL}(q\Vert\rho_\theta),
```

可得到

```math
q_\gamma(x)
\propto
\rho_\theta(x)
\left[\epsilon+\widehat{\Delta}(x)\right]^\gamma,
```

其中 $\epsilon>0$ 防止零点奇异，$\gamma=0$ 退化为无偏参考分布。若 $\rho_\theta(x)\propto e^{-\beta E_\theta(x)}$ 且偏置静态，则可写成

```math
E_\text{eff}(x)
=
E_\theta(x)
-
\frac{\gamma}{\beta}
\log\!\left[\epsilon+\widehat{\Delta}(x)\right].
```

这只是一个 KL 正则探索分布，不是“主动学习风险下降的全局最优分布”。基础模型能量 $E_\theta$ 也不等于 DFT 真势能，因此需要两条轨迹流：

1. **声明目标测度的参考流**：只用于估计 $M_\text{deploy}$。若目标是某个物理系综 $\rho_\text{deploy}$，参考流必须从该系综采样，或使用有依据的重要性重权；若目标有意包含缺陷枚举、增强采样与多个温压条件，则应明确声明人工混合测度

   ```math
   \widetilde{\rho}
   =
   \sum_k \alpha_k\rho_k,
   \qquad
   \alpha_k\ge0,\quad \sum_k\alpha_k=1,
   ```

   并将 $M_\text{deploy}$ 改称相对于 $\widetilde{\rho}$ 的目标矩阵，不能再称“无偏物理部署分布”。

1. **目标偏置候选流**：只用于发现候选，不未经重权地更新目标矩阵。

若必须用偏置流估计部署量，应使用重要性权重 $w(x)=\rho_\theta(x)/q_\gamma(x)$，并报告有效样本量（effective sample size, ESS）。ESS 衡量加权样本相当于多少个等权独立样本：

```math
\operatorname{ESS}
=
\frac{\left(\sum_i w_i\right)^2}
{\sum_i w_i^2}.
```

MD 帧还存在时间自相关。若归一化自相关为 $\varrho(k)$，可进一步报告近似有效样本量

```math
N_\text{eff}
\approx
\frac{\operatorname{ESS}}
{1+2\sum_{k\ge1}\varrho(k)}.
```

重要性权重 ESS 很高但轨迹高度相关时，目标矩阵仍可能估计不足。

偏置还需 $\epsilon$ 数值下限、偏置能上限、偏置力上限、随机探索下限和 DFT 成功率监控。目标方向对齐不等于构型物理可行，ZBL / 最短距离只能作为安全信号，不能代替 DFT 可行性模型。

**导数阶数边界：**

- 最后一层激活版 $\widehat{\Delta}$ 的偏置力需要激活对坐标的导数；
- 完整 $\phi=\nabla_\theta E$ 版需要参数—坐标混合二阶导；
- 若 $\phi^F=\nabla_\theta F$ 再对 $\widehat{\Delta}$ 求坐标梯度，通常需要能量的三阶混合导。

当前 SeZM 实现已验证力损失所需的二阶导，但尚未验证三阶导。因此第一版只应尝试最后一层能量特征偏置；力 NTK 先用于离线选点，不能直接宣称现有二阶反向传播已经支持其偏置 MD。

在这些问题获得实验支持前，准确定位是**有明确先例支撑的系统研究框架**，而不是已经成立的原创基础算法。

## 28. SeZM / DPA4 案例：现有能力与实现缺口

当前 SeZM / DPA4 的 PyTorch 实现具备部分基础能力，但尚未实现本章的目标感知实验设计或偏置动力学。下文按“现有能力—实现缺口”分别说明。

**可直接支持离线原型的能力：**

- `dp embed` 命令可从 PyTorch 训练检查点（`.pt` checkpoint）导出结构特征 `structural_feature` 与原子特征 `atomic_feature`，适合最终能量输出头的离线特征筛选。
- LoRA 微调与检查点合并功能可用于选点后的统一微调协议。
- `DPA4Wrapper` 可运行 NVE（固定粒子数、体积和总能量）、NVT 与 NPT 模拟，适合产生部署参考轨迹与候选轨迹。
- ZBL（Ziegler–Biersack–Littmark）短程排斥与区间桥接可提供极短程安全参考，但不能直接充当数据正确性标签。

**仍需实现与验证的能力：**

- `structural_feature` 只对应最终输出权重；LoRA、径向网络和注意力等参数的梯度草图需要新路径。
- 二阶反向传播支持力损失所需的二阶导，但不等于已经支持 §26 力切向偏置所需的三阶混合导。
- `dp embed` 当前针对 `.pt` 训练检查点；提前编译的 `.pt2` 推理包不提供特征导出接口。
- 当前实现尚无 $M_\text{deploy}$、Woodbury 选点函数、重要性重权、目标偏置力或对应的提前编译图。
- 提前编译（ahead-of-time compilation, AOT）把模型图编译成部署包；应用二进制接口（application binary interface, ABI）规定 C++ / LAMMPS 如何调用该包。把 $(\Sigma,M)$ 写入 `.pt2` 不等于偏置力自动可用，仍需新增导出图、动态形状验证和 ABI。
- 多 GPU LAMMPS 路径对 ZBL 与源冻结传播门（Source Freeze Propagation Gate, SFPG）区间桥接仍有限制，不能预设多 GPU、桥接和目标偏置可以直接组合。

因此最小可行版本应是**离线最终输出头原型**：独立生成部署参考集与候选池，导出 `structural_feature`，在 Python 中计算选点分数，选点后按固定协议微调。在线偏置 MD、力 NTK 和 AOT / LAMMPS 部署属于后续独立工程阶段。

## 29. 各类任务的完整流程

各任务共享分层组织方式，但使用不同的标签模型、目标风险与验证协议。

### 29.1 任务①/④：数据清洗与跨领域整合

- **流式粗筛（§22）**：对每个 DFT 任务分别建立分层码本、加权 MinHash 和覆盖簇；保留原簇样本数与随机审计样本。压缩率由召回率和下游验证决定。
- **标签审计（§23）**：物理规则产生疑点标记；分层复算估计标签可信概率 $p_\text{clean}$；确认错误的删除，其余按稳健似然或概率加权。
- **目标精选（§24）**：用独立无偏部署集构造 $M^{(t)}$，先完成风险下降校准，再决定是否采用 Fisher 精选。
- **跨任务训练（§25）**：结构去重、采样概率和损失加权分别验证，不把不同泛函或磁态强行合并。
- **产出**：带数据来源、任务、覆盖簇、原簇样本数、标签可信概率和复算证据的数据版本，而不是预先承诺“信息等价”的核心集。

### 29.2 任务②：快速势函数生产

- **部署参考集**：若目标是物理系综，只用该系综的普通 MD 或经验证的重权样本构造；增强采样和人工枚举进入独立候选池。若科学目标本身是多个温压、缺陷和反应通道的加权合集，则预先声明 $\widetilde{\rho}=\sum_k\alpha_k\rho_k$ 及权重，并按该混合测度构造参考集。无论哪种情况，参考集都不与后续偏置候选池混用，并报告时间自相关修正后的有效样本量。
- **候选池**：第一阶段使用无偏 MD 以及温压、缺陷和应变枚举；只有离线选点分数已经通过真实风险下降校准后，才试验 §26 的目标偏置。
- **选择**：对比分层随机、BAIT、信息匹配、力感知 NTK、DPGEN 模型分歧指标和 DIRECT；按相同 DFT 机时而非相同帧数比较。
- **微调**：使用完全固定的 LoRA 参数子空间、学习率、回放样本（replay）与早停协议。回放样本的选择与防遗忘效果需要独立消融，不能自动归功于选点方法。
- **迭代**：轮数由独立部署验证风险、DFT 成功率和实际边际收益决定，不预设 2–4 轮或 50–200 帧必然足够。

### 29.3 任务③：蒸馏数据集构建

- **双轨轨迹生成（rollout）**：教师轨迹提供稳定参考，学生轨迹暴露学生诱导的分布漂移；两者都保留来源标识。
- **选择目标**：师生分歧、学生后验方差和学生特征覆盖分别作基线，不预设它们的乘积一定最优。
- **曲率监督**：以 Amin 等的 Hessian 蒸馏和 Rodriguez 等的 PHL 为直接基线；HVP 数量、参考 Hessian 成本和学生收益需要独立消融。
- **数据增广**：随机位移与应变只在教师预测稳定、几何通过安全检查的范围使用；教师系统性错误会传递给学生，因此仍需少量 DFT 审计集。

## 30. 适用条件与可证伪假设

§24 的闭式公式只在固定参数特征、线性高斯观测和正确噪声模型下精确；实际 SeZM 还存在参数线性化误差、模型偏差、部署分布误差和有限梯度草图误差。拟议框架因此不具有“整体正确性证明”，只有以下可证伪假设：

1. **代理有效性假设**：$\widehat{\Delta}_c$ 与真实微调风险下降 $\Delta_\text{real}$ 在目标任务上有显著正排序相关。
1. **目标条件化假设**：独立 $M_\text{deploy}$ 比 $M=I$、候选池 Fisher 和纯后验方差更能降低部署验证风险。
1. **先验有效性假设**：经过 $\kappa$ tempering 的 $F_\text{pre}$ 比各向同性先验更好；若基础模型负迁移严重，该假设可能失败。
1. **向量观测假设**：能量—力联合 Woodbury 比仅能量最后一层特征更有效，并且额外混合导数成本可接受。
1. **标签审计假设**：经复算校准的 $p_\text{clean}$ 能提高数据质量；未经复算的物理疑点标记不应被计入该结论。
1. **偏置假设**：KL 正则目标偏置比 HAL、UDD 或总不确定性偏置取得更高的实际 DFT 风险下降，同时不降低 DFT 成功率和重要性重权 ESS。
1. **粗筛假设**：码本与加权 LSH 在精确近邻审计集上保持足够召回率，且压缩后的模型性能与 MD 稳定性不显著下降。

任何一个关键假设失败，都应缩减框架，而不是增加更多补丁。

## 31. 验证方案

**基线（全部对比）**：分层随机（从同一候选池抽样，**同 DFT 机时预算**而非同样本数）、FPS、DIRECT、DPGEN 模型分歧指标、纯梯度后验、BAIT、Kurniawan 等的信息匹配 / ALIM，以及 Varga-Umbrich 等的力感知 NTK。至少使用 3 个随机种子；主动学习超参数不能用最终测试集调优。

**消融**：最终输出头与 LoRA 特征；标量 Sherman–Morrison 与向量 Woodbury；$M_\text{deploy}$、$M=I$ 与候选池 Fisher；$\kappa F_\text{pre}$ 与 $\lambda I$；仅能量与能量—力联合监督；普通 MD、HAL / UDD 与 KL 目标偏置；无标签审计、仅疑点标记与复算校准；保持原分布的原簇样本数权重与主动密度均衡。

**指标**：主指标是部署测试集上的力均方根误差（root mean squared error, RMSE）和能量平均绝对误差（mean absolute error, MAE）随总机时——包括特征提取、选点、失败 DFT 与微调——变化的曲线；同时报告 MD 失效率、径向分布函数（radial distribution function, RDF）、扩散系数、缺陷形成能和声子谱等目标物性。核心代理还必须报告 $\widehat{\Delta}$ 对 $\Delta_\text{real}$ 的排序相关与前 $k$ 项遗憾值。标签审计专项用统一 DFT 复算集测精确率与召回率；粗筛专项报告近重复召回率、码本量化误差、峰值内存和端到端吞吐。

**最小闭环实验**：第一阶段不做在线主动学习，只做 §24.8 的风险下降校准。第二阶段在同一固定候选池和机时预算下比较目标设计、分层随机、BAIT / 信息匹配、力感知 NTK 与模型分歧指标。单一体系上的正结果只能证明该体系中的有效性，不能证明框架普适；至少还需一个窄目标微调任务、一个强候选偏移任务和一个高冗余清洗任务。

## 32. 风险、边界与未决问题

- **模型偏差**：后验方差很小不代表基础模型正确；需要分布外（out-of-distribution, OOD）DFT 审计和风险膨胀校准。
- **参数子空间失配**：输出头特征可能太弱，LoRA / 全梯度又可能太贵；必须通过 $\Delta_\text{real}$ 校准选择。
- **部署参考偏差**：当前模型可能访问错误的热力学分布；增强采样与人工结构枚举只能缓解，不能保证覆盖真分布。
- **非次模选择**：逆迹风险没有普适 $1-1/e$ 保证，普通贪心可能陷入次优；应与凸松弛、前向选择—反向剔除和对数行列式代理比较。
- **噪声不可辨识**：高残差与低密度不足以区分异常标签和模型欠表达；没有统一复算集就不能声称清洗正确。
- **尺寸与单位偏置**：总能量特征随原子数求和，力分量数量也随体系增大；所有雅可比矩阵与噪声必须按任务、单位和体系尺寸白化。
- **码本与 LSH 偏差**：稀有码字可能是量化噪声；超大哈希桶、布隆过滤器碰撞与跨元素混淆会损害召回率。
- **高阶导和部署**：力切向偏置可能要求三阶导；当前 SeZM `.pt2`、多 GPU、ZBL 与目标偏置尚未形成可用组合。
- **跨任务权重**：样本选择与损失加权不等价；不同泛函或磁态的标签不能按单一“精度”排序。
